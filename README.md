# 🎬 Cinema Management System

A Java-based application for managing cinema operations, including movies, screenings, cinema halls, seats, customers, employees, reservations, and payments.

---

## Features

### Movies & Screenings

* Add and manage movies.
* Schedule screenings and assign them to cinema halls.
* Manage screening times.

### Cinema Halls & Seats

* Manage cinema halls and available seats.
* Assign seats to individual screenings.

### Customers

* Add and manage customer information.
* Use customer data when creating reservations.

### Reservations

* Create and manage ticket reservations.
* Select seats for specific screenings.
* Track reservation status.

### Payments

* Manage payment information related to reservations.
* Track payment status.

### Employees

* Store and manage employee information.
* Organize data related to cinema staff.
